Hosting empresarial:
qué incluye el servicio

El hosting aloja los archivos y datos necesarios para que una web o aplicación esté disponible. El catálogo de Rtres incluye planes Cloud, WordPress y zona EUR. La elección depende del tráfico, recursos, tecnología, ubicación del público y necesidades de soporte.

¿Para quién es?

Empresas que necesitan alojamiento para su web, tienda o aplicación y un interlocutor para su gestión.

Antes de empezar.

¿Qué plan necesita mi sitio?

Revisamos tecnología, tráfico, almacenamiento y uso de la base de datos antes de recomendar el plan.

¿Hay alojamiento para público europeo?

El catálogo contempla hosting zona EUR. Deben confirmarse ubicación, recursos y condiciones vigentes.

¿Incluye backups y disponibilidad garantizada?

Las condiciones de respaldo, restauración y disponibilidad deben constar en el plan contratado. No se presume un SLA general.
