APIs de validación:
qué incluye el servicio

Las APIs de validación permiten consultar datos desde una aplicación existente. El catálogo de Rtres contempla validación de DNI, RUC y cuentas bancarias. Disponibilidad, campos de respuesta, límites y condiciones de uso se revisan por servicio antes de contratar la integración.

¿Para quién es?

Equipos de producto y desarrollo que necesitan incorporar validaciones a sus flujos de registro o gestión.
